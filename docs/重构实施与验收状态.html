  • Agent G0（签名运行证明）、G1（节点身份）、G4（证据对齐）确定性护栏； Proof Authority 将证明与 CAS、SQLite、Event Ledger 三重绑定。

  • Release 默认要求 G0–G7，候选 Gate hash hard-bind、目标 compare-and-swap、 路径穿越与 symlink 逃逸阻断、失败回滚 journal。
  • Graph、Wiki、Cross-link、LCA Binding、BOM、Publication 领域适配器。
  • 35 个基础执行资产按 SHA-256 冻结迁移；ICT 生产 fixture 另含完整 132 节点的 图、Wiki、sigil、来源与 LCA 注册表及 viewer 资产；原项目不作为运行写入目标。

  • Goal Alignment 控制平面已落地：版本化 Goal Contract、九维质量轨迹、False Pass/False Block/重复故障/质量退化检测、因果诊断、L0/L1/L2 修复路由、受控 System Change Candidate，以及 Sandbox→Shadow→Canary→Promotion→Rollback 凭证链。
  • Worker 在每个 Task 终态自动审计；Dashboard 与 CLI 已提供目标对齐查询、主动审计、 人工逃逸反馈与变更控制入口。运行中 Job 无权修改代码、Goal Contract 或发布权限。
